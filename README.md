# ⚡ Calculadora de Consumo de Energia

## 💡 Sobre o projeto

Este projeto foi desenvolvido em Python com o objetivo de calcular o consumo mensal estimado de energia elétrica de um aparelho.

O programa solicita o nome do aparelho, sua potência em watts e o tempo médio de utilização diária.

## 🐍 Linguagem utilizada

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python&logoColor=white)

## ⚙️ Fórmula utilizada

O consumo mensal é calculado utilizando a seguinte fórmula:

**Consumo mensal = (potência × horas por dia × 30) / 1000**

O resultado é apresentado em **kWh/mês**.

## ▶️ Como executar

1. Instale o Python.
2. Abra o projeto no Visual Studio Code.
3. Abra o arquivo `app.py`.
4. Execute o programa.
5. Informe o nome do aparelho, a potência em watts e as horas de uso diário.
6. O programa apresentará o consumo mensal estimado.

## 📊 Exemplo

**Entrada:**

- Aparelho: Geladeira
- Potência: 150 W
- Uso diário: 10 horas

**Resultado:**

- Consumo estimado: 45.00 kWh/mês
